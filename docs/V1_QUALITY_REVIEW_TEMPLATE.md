# V1 설명 품질 수동 검토 양식

속도와 HTTP 200만으로 설명 정확도를 판단하지 않는다. 아래 표는 실제 메뉴 원문과 LLM 설명을 사람이 대조할 때 한 행씩 작성한다. 검토하지 않은 항목에는 점수를 넣지 않고 `미검토`로 둔다.

## 항목별 검토

| 기준 | 판정 | 근거·오류 사례 |
|---|---|---|
| 식당이 명시한 메뉴명·재료·옵션을 정확히 반영 | 통과 / 실패 / 미검토 | |
| 일반 음식 지식을 식당 사실처럼 단정하지 않음 | 통과 / 실패 / 미검토 | |
| 맛·향·식감의 추정을 추정으로 표현 | 통과 / 실패 / 미검토 | |
| 존재하지 않는 재료·옵션·가격을 만들지 않음 | 통과 / 실패 / 미검토 | |
| 선택한 변형·옵션만 조합 설명에 반영 | 통과 / 실패 / 미검토 | |
| 알레르기·건강·인기 정보를 근거 없이 단정하지 않음 | 통과 / 실패 / 미검토 | |
| 한국어가 짧고 자연스러우며 이해하기 쉬움 | 통과 / 실패 / 미검토 | |
